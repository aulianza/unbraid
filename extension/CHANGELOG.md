# Changelog

## 0.1.0

First release.

- Splits a messy working tree into atomic commits with AI-written messages
- Review panel: rename, merge, reorder, and remove commits before anything is written
- Changed files in a native tree with your icon theme, plus stage, unstage, and discard
- Undo the last run — restores HEAD and your staging exactly
- Branch switcher, recent commits, and sync
- Settings for commit size, splitting files that mix concerns, and which AI to use
- Works free with an existing Claude Code subscription, or any OpenAI-compatible
  provider including a model running locally on your own machine
